# 2026.326.0834 — refactor(builder)!: serve every `pixi` leg through the one shared builder dispatch

## Summary

The `pixi` builder plugin serves all three builder legs through the ONE shared dispatch, `sdk.InvokeBuilder` (opencharly/sdk#608). `plugin.go`'s `Invoke` delegates `OpResolve`, `OpCollectContext` and `OpReverse` to it, and an op no builder serves is still refused. The stage template, the payload and the package output come from `sdk/kit`, owned once for every builder. Before, each builder plugin carried its own copy of those three legs — four byte-identical copies (R2).

Every leg is pinned to this plugin's own word: two tests compare `Invoke`'s reply against kit's own for the literal word `"pixi"` on `resolve`, `collect-context` and `reverse`, so a dispatch routed to any other builder fails on all three.
