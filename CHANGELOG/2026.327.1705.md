# 2026.327.1705 — chore(deps): adopt sdk v0.2026327.1653 — the pixi stage pins HOME/PIXI_HOME

## Summary

Adopt `github.com/opencharly/sdk v0.2026327.1653` — the release that merged opencharly/sdk#627, where the emitted pixi builder stage pins the environment location instead of inheriting it from the base image:

```diff
 USER {{.UID}}
 WORKDIR {{.Home}}
+ENV HOME={{.Home}} PIXI_HOME={{.Home}}/.pixi
 ...
-RUN … {{.InstallCmd}} && rm -f {{.Manifest}} pixi.lock
+RUN … {{.InstallCmd}} && test -d {{.Home}}/.pixi && rm -f {{.Manifest}} pixi.lock
```

**Why it matters here.** This plugin is the emitter's consumer: every candy with a `pixi.toml` gets its stage from this module. On the rebuilt Arch base the env landed outside the box home and the final image carried no `/home/user/.pixi`, reddening every check that reads `<home>/.pixi/envs/default/bin/python` (measured on `opencharly/pod-comfyui#49`'s composed bed; filed as `opencharly/pod-comfyui#51`).
